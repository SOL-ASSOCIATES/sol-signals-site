# Sol Signals - public data pages

Generated static site for Sol Signals, Sol Associates' free weekly public-data intelligence
digest on Romania's energy build-out (tenders, grid, regulation, weather context).

This repository holds ONLY generated HTML, CSS and images, rebuilt from
`scripts/web_platform/build_signals_site.py` in the private `sol-associates-code` repository
and pushed here by `scripts/web_platform/deploy_signals_site.py`. It never contains source
data, databases, credentials, or client-identifying material - see that script's own gates
before assuming otherwise.

Live site: https://sol-associates.github.io/sol-signals-site/
